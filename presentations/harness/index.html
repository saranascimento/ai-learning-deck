Controle

O que existe aqui dentro?

Conceito

Uma recomendação apresentada como evidência de um incidente precisa estar sustentada pelo contexto fornecido.

Como mantemos o comportamento do sistema dentro desse limite?

Guardrail

mecanismo usado para manter o comportamento de um sistema de IA dentro de limites ou regras definidos

não é necessariamente um Prompt — e não tem uma implementação universal

"estamos dentro dos limites?"

Conceito

Temos uma expectativa ou regra.

Como verificamos se o resultado realmente atende a ela?

Validation

processo de verificar se uma entrada, saída ou estado atende às condições esperadas

"isso atende ao que esperávamos?"

Conceito

A validação produziu um resultado.

A execução pode avançar?

Gate

mecanismo que decide se uma execução pode avançar, com base em uma condição ou resultado

"podemos avançar?"

Comparação

Guardrail limites de comportamento
Validation verifica uma condição
Gate decide a progressão

não precisam existir sempre como três componentes separados

Conceito

A operação falhou.

Tentamos de novo?

Retry

executar novamente uma operação quando existe possibilidade razoável de uma nova tentativa funcionar

nem toda falha é retryable — e sem limite, tentaríamos para sempre

"vale tentar novamente?"

Conceito

E se repetir exatamente a mesma coisa não resolver — mas o resultado puder ser corrigido?

Repair

tentar corrigir algo inválido antes de continuar

Retry ≠ Repair

"podemos corrigir?"

Conceito

A estratégia principal não conseguiu produzir o resultado necessário.

Existe um plano B?

Fallback

alternativa utilizada quando a estratégia principal não consegue produzir o resultado esperado

"qual é a alternativa?"
